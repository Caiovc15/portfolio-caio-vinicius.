# Portfólio — Caio Vinícius Galdino

Portfólio pessoal de Caio Vinícius Galdino, com trajetória na IA PhD, projetos de sistemas agênticos, currículo técnico e trabalhos visuais.

## Tecnologias

HTML, CSS e JavaScript, sem dependências ou etapa de compilação.

## Abrir localmente

Abra `index.html` no navegador. Para usar um servidor local com Python:

```sh
python -m http.server 8000
```

Acesse http://localhost:8000.

## Estrutura

- `index.html`: conteúdo e estrutura.
- `style.css`: estilos, animações e layout responsivo.
- `script.js`: galeria ampliável e demonstração de fluxo.
- `assets/`: fotografia e trabalhos visuais.

A demonstração de fluxo é ilustrativa; não executa operações reais em sistemas externos.
